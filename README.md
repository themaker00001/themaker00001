I move between **research and production**: reading a paper on Monday, reimplementing its core idea by Wednesday, and shipping it as a real pipeline by the weekend. Most of my work lives at the intersection of **LLMs/SLMs, agents, and real-time multimodal systems** (voice + avatars) — usually with a strong bias toward running fully offline/on-device rather than behind an API.

- 🔭 Currently: distilling large-teacher signal into small, deployable models, and building local-first agent/voice tooling
- 🧪 Research habit: pick an industry blog post or paper, reimplement it from scratch, and see where the real bottlenecks are
- ⚡ Philosophy: prototype in Python, push the hot path to Rust or C++ once it's worth optimizing
- 🌱 Currently deep in: agent memory architectures, SLM distillation, and low-latency inference
